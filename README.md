# 末日房東模擬器 - Apocalypse Landlord Simulator

一個基於末日殭屍背景的房東租屋經營遊戲，在殭屍橫行的世界中平衡生存與獲利，體驗策略性資源管理和租客關係經營的挑戦。

## 🎮 遊戲特色

### 末日背景策略經營
在殭屍病毒肆虐的世界中，經營一棟庇護所，平衡租客需求、資源管理和生存壓力。每個決策都影響著所有人的命運。

### 多元租客管理
管理5種職業租客，每種都有獨特技能和風險：
- **👩‍⚕️ 醫生**：治療感染、健康檢查、醫療生產
- **👷 工人**：維修建築、房間升級、防禦加固
- **🌾 農夫**：食物生產、野外採集、院子管理
- **🪖 軍人**：安全防護、夜間警戒、戰鬥支援
- **👴 長者**：糾紛調解、經驗指導、社交協調

### 深度資源系統
統一管理5種關鍵資源：
- **🍖 食物**：維持生命的基本需求
- **🔧 建材**：房屋維修和升級材料
- **💊 醫療**：治療疾病和檢測感染
- **⛽ 燃料**：維持房屋運作的能源
- **💵 現金**：支付服務和應急開支

### 動態事件挑戰
面對4類隨機事件考驗：
- **🧟 隨機事件**：殭屍襲擊、商隊造訪、資源發現
- **⚡ 衝突事件**：租客糾紛、資源爭奪、感染恐慌
- **🎯 特殊事件**：醫療緊急、建築危機、重大決策
- **📜 腳本事件**：里程碑事件、季節變化、劇情推進

## 🚀 快速開始

### 立即遊玩
1. **下載遊戲**：
   - `src/index.html`

2. **開啟遊戲**：
   - 使用現代瀏覽器開啟HTML檔案
   - 建議使用 Chrome 61+, Firefox 60+, Safari 10.1+

3. **開始遊戲**：
   - 🏠 **收租**：定期收取租客租金
   - 👥 **管理租客**：雇用合適的倖存者
   - 🛠️ **使用技能**：發揮租客專業能力
   - 🌱 **資源管理**：平衡消耗與獲取
   - 🌙 **推進天數**：體驗動態事件

### 基礎玩法指南

#### 租客經營策略
- **面試評估**：觀察訪客外觀，小心感染者
- **職業搭配**：不同職業間有相性加成或衝突
- **技能運用**：主動技能需要資源，被動技能自動生效
- **滿意度管理**：滿意的租客更願意配合和幫助

#### 資源管理技巧
- **收入來源**：租金、院子採集、租客搜刮、商人交易
- **支出控制**：日常消耗、技能成本、緊急支出
- **庫存平衡**：避免資源過度集中或短缺
- **交易時機**：善用商人和商隊的交易機會

#### 生存危機應對
- **感染控制**：及時隔離和治療感染租客
- **防禦升級**：提升建築防禦抵禦外部威脅
- **衝突調解**：使用長者技能緩解租客糾紛
- **應急準備**：維持足夠資源應對突發事件

## 🎯 遊戲機制亮點

### 技能系統
15個獨特技能分為三大類：
- **主動技能**：消耗資源，主動觸發強力效果
- **被動技能**：持續生效，提供穩定加成
- **特殊技能**：限制次數，帶來永久性改善

### 交易網絡
4種交易管道提供靈活的資源流通：
- **租金收取**：現金優先，資源抵付，房間加固額外收益
- **商人交易**：基於租客職業的專業化交易選項
- **商隊貿易**：大量物資的批發交換機會
- **互助協作**：租客間資源分享和緊急支援

### 動態平衡
遊戲採用動態機率系統，根據當前狀況調整事件發生機率：
- 資源充足時增加挑戰事件
- 危機時刻提供救援機會
- 租客關係影響事件選項
- 建築防禦決定威脅等級

## 🎮 遊戲設計理念

### 策略深度
遊戲避免單純的數值成長，著重策略選擇和資源分配。每個決策都有機會成本，需要考慮短期利益與長期發展的平衡。

### 角色互動
租客不是單純的資源生產者，而是有個性、需求和相互關係的角色。管理好人際關係往往比資源管理更具挑戰性。

### 不確定性
末日背景下的不確定性是遊戲核心。玩家需要在資訊不完整的情況下做出決策，並承擔相應後果。
