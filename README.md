# 末日房東模擬器

基於末日殭屍背景的房東租屋經營遊戲。在殭屍橫行的世界中管理租客、資源和生存挑戰，體驗策略性的經營決策。

## 🎮 核心特色

### 租客經營系統
管理5種職業租客，每種具備獨特技能和風險特性：
- **醫生**：治療感染、健康檢查、醫療物品生產
- **工人**：建築維修、房間加固、防禦升級
- **農夫**：食物生產、野外採集、院子管理
- **軍人**：安全防護、夜間警戒、戰鬥支援
- **長者**：糾紛調解、經驗指導、社交協調

### 資源管理系統
統一管理5種關鍵資源的獲取、消耗和流轉：
- **食物**：維持生命的基本需求
- **建材**：房屋維修和升級材料
- **醫療**：治療疾病和檢測感染
- **燃料**：維持房屋運作的能源
- **現金**：支付服務和應急開支

### 統一交易系統
整合3種交易管道，提供完整的資源流通機制：
- **租金收取**：現金和資源抵付的彈性收租機制
- **租客交易**：基於關係度的個人化交易選項
- **互助協作**：租客間自動資源分享和緊急支援

### 技能執行系統
15個技能分為三大類，提供多樣化的策略選擇：
- **主動技能**：消耗資源，主動觸發強力效果
- **被動技能**：持續生效，提供穩定加成
- **特殊技能**：限制次數，帶來永久性改善

### 動態事件系統
4類事件提供不同的挑戰和機會：
- **隨機事件**：殭屍襲擊、商隊造訪、資源發現
- **衝突事件**：租客糾紛、資源爭奪、感染恐慌
- **特殊事件**：醫療緊急、建築危機、重大決策
- **腳本事件**：里程碑事件、季節變化、劇情推進

## 🚀 快速開始

### 啟動遊戲
1. **開啟遊戲**：使用現代瀏覽器開啟 `src/index.html`
2. **系統需求**：Chrome 61+、Firefox 60+、Safari 10.1+ （ES6模組支援）
3. **開發模式**：使用 `src/dev-test.html` 進行測試和除錯

### 基本操作
- **收取租金**：定期收取租客租金，支援現金和資源抵付
- **雇用租客**：面試申請者，評估技能和感染風險
- **租客交易**：查看個別租客的交易選項，執行購買或出售交易
- **使用技能**：發揮租客專業能力，解決各種問題
- **資源管理**：平衡資源消耗與獲取，維持庫存平衡
- **推進天數**：體驗隨機事件和日常挑戰

### 策略要點
- **職業搭配**：不同職業間有協同效應或衝突風險
- **關係管理**：維持良好租客關係獲得更優惠的交易價格
- **滿意度平衡**：滿意的租客更願意配合和提供幫助
- **風險評估**：注意租客的感染風險和行為異常
- **資源平衡**：避免過度依賴單一資源來源
- **應急準備**：保持足夠資源應對突發危機

## 🔧 技術架構

### 系統設計
- **模組化架構**：ES6 import/export，零外部依賴
- **配置驅動**：遊戲參數來自JSON檔案，支援熱更新
- **事件通信**：EventBus實現模組間解耦通信
- **狀態管理**：GameState集中式狀態控制和歷史追蹤
- **型別安全**：JSDoc註解配合TypeScript檢查

### 核心模組
- **DataManager**：統一資料管理，並行載入配置檔案
- **GameState**：中央狀態管理，支援路徑式存取和統一人物ID系統
- **EventBus**：事件驅動通信，支援智慧前綴解析

### 業務模組
- **ResourceManager**：資源流轉控制，閾值監控和轉移驗證
- **TenantManager**：租客生命週期管理，統一ID系統和滿意度追蹤
- **TradeManager**：統一交易系統入口，協調多種交易類型
- **SkillManager**：技能執行管理，支援三種技能類型
- **DayManager**：每日循環處理，資源消耗和事件觸發

### 部署特性
- **GitHub Pages原生支援**：無需建置工具，直接部署
- **配置熱更新**：修改JSON檔案無需重新部署
- **除錯友善**：內建完整的狀態監控和統計功能

## 🎯 遊戲機制

### 策略深度設計
- **決策影響**：每個選擇都有機會成本和長期後果
- **資訊不對稱**：需要在不完整資訊下做出判斷
- **多重目標**：平衡生存、獲利和人際關係
- **風險回報**：高風險選擇提供對應的高回報潛力

### 動態平衡機制
系統根據當前狀況動態調整遊戲難度和機會：
- 資源充足時增加挑戰事件機率
- 危機時刻提供救援機會
- 租客關係影響事件選項和結果
- 建築防禦程度決定外部威脅等級
